## 填写原则

1. **可验证**：每条交互尽量给出来源（文件名、注解、URL）
2. **标注三类**：事实 / `[推断]` / `[原型未标明]`
3. **不写验收标准**：验收放在落地 PRD §5
4. 用户确认盘点后，再进入概念版；盘点有重大更新时同步改 §6、§7
