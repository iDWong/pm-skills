# 线上站点 / 本地 HTML 功能盘点

> 目标：从 **可访问页面** 归纳功能模块与用户动线。侧重行为与信息结构，**不**提取视觉 tokens（那是 `ui-ux-pro-max --design-system` 或 `design-system` 的活）。

## 1. 输入与可达性

| 输入 | 方法 |
| --- | --- |
| 公开 URL | **优先 Playwright MCP**（见 [`playwright-mcp-capture.md`](playwright-mcp-capture.md)）；未配置时用 `WebFetch`；SPA / 超时 / 空壳时应用 MCP |
| 需登录 / 内网 / SSO | **不得猜测内页**；按 [`auth-gated-sites.md`](auth-gated-sites.md) 分段盘点 + 请用户选补救方案；不可达页标 `[未访问-需登录]` |
| 本地 `web/` 镜像 | 直接 `Read` HTML；按 `href` 追链 |
| SPA（大量空壳 div） | 抓取可见文案与导航；标注 `[SPA-仅静态壳]`，动线标 `[推断]` |

**范围**：默认盘点主导航可达页；用户指定「只分析结算流程」等则缩小范围。

## 2. 盘点流程

```text
1. 首页 → 提取主导航、页脚链接、全局搜索/登录入口
2. BFS 或按用户优先级遍历内页（控制深度，避免爬虫失控）
3. 每页填写 inventory-template §4 单页小节
4. 合并跨页重复模块（页头、页脚、购物车浮层等）
5. 绘制主路径 Mermaid 草稿（写入盘点稿 §5，供 PRD §3 复用）
```

单站 >20 页：先交 **站点地图表**，与用户确认范围后再逐页细化。

## 3. 每页关注要素

- **页面类型**：列表 / 详情 / 表单 / 仪表盘 / 营销落地 / 错误页
- **主 CTA**：唯一或并列主按钮及其目标
- **表单字段**：名称、是否必填、格式提示（从 label/placeholder 读）
- **列表/表格**：列名、筛选、排序、分页模式
- **反馈态**：toast、inline 错误、空状态、加载骨架（若 HTML 含多套态）
- **权限暗示**：「请登录」「无权限」文案、隐藏菜单项

## 4. 动线推断规则

| 依据 | 标注 |
| --- | --- |
| 明确 `href` 或表单 `action` | 直接记录 |
| 按钮无链，行业惯例（如「加入购物车」） | `[推断]` |
| JS 路由不可见 | `[待确认]` |

**禁止**：把未验证的推断写进 PRD 验收标准。

## 5. 与 Axure 盘点的差异

| 维度 | 线上站点 | Axure |
| --- | --- | --- |
| 站点图 | 从链接爬取 | document.js sitemap |
| 交互 | 多为静态快照 | data.js / 注解较全 |
| 业务规则 | 常不可见 | 设计者可能写在备注 |
| 版本 | 线上即真理 | 导出时间点快照 |

混合输入时，盘点稿分 **§A 原型** / **§B 线上** 两节，冲突处列对照表请用户裁定。

## 6. 限制说明（写入盘点稿文首）

- 未执行真实点击/接口请求
- 动态数据为示例或空
- 登录后流程可能不完整

用户需完整规则时，应补充口述或既有 PRD/接口文档。
