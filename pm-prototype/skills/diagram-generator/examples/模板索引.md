**用法**：挑一个结构最接近的 XML 复制过去改内容，不要从空白 XML 起手——
坐标、连线锚点、样式串手写极易出错。

## 怎么引用

模板路径相对本目录。跨技能引用时用解析器拿绝对路径，不要硬编码技能库根：

```bash
DG="$(resolve_skill diagram-generator)"      # 解析器见 pm-prd-spec/SKILL.md 文首
cp "$DG/examples/swimlane.xml" tools/svg/my-flow.xml
```

渲染与校验见 `../SKILL.md` 的「渲染」一节（`scripts/render-diagram.*` 需要 `config.json` 里的 `diagramApiUrl`；
`scripts/validate-diagram.*` 是本地的，不需要端点）。
