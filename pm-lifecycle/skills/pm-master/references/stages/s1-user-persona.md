## 阶段1：用户画像

**目标**：基于市场调研，创建详细的用户画像

**输入**：`docs/market-research.md`（阶段0输出）

**执行方式**：调用 `pm-user-persona` skill

**传入上下文**：
```
请读取 docs/market-research.md，基于目标用户群体创建用户画像。

要求：
- 创建 2-3 个典型用户画像
- 每个画像包含：基本信息、目标、痛点、使用场景
- 绘制用户旅程地图
```

**输出**：`docs/user-persona.md`

**完成标志**：用户画像文档已写入，包含至少2个典型用户画像
