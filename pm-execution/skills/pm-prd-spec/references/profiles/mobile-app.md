# Profile：移动端 APP

iOS / Android 原生，或 React Native / Flutter。有安装包、系统权限、推送、版本更新。

## 附加铁律

- **M1 每个页面必写四态**：正常、空、加载、异常（无网络 / 弱网 / 接口失败）。移动端断网是常态，不是边界情况。
- **M2 返回必须写清去哪**：返回上一页还是回首页？返回后原页面状态（滚动位置、已填表单、播放进度）保不保留？系统返回手势和页面内返回按钮行为是否一致？
- **M3 权限申请必写三件事**：什么时机申请、申请前的说明文案原文、用户拒绝后的降级路径。上来就弹系统权限框是最常见的差评来源。
- **M4 安全区必须显式声明**：顶部刘海/灵动岛、底部横条/虚拟键，哪些元素要避让、哪些要延伸到边缘。

## 页面类型（只用这八种）

`启动/引导页`、`Tab 主页`、`信息流列表`、`内容详情页`、`发布/表单页`、`个人中心`、`设置页`、`浮层（弹窗/底部面板/Toast）`

## 信息架构写法

页面栈 + Tab 结构：

```
App
├── 启动页 → 引导页（仅首次）→ 登录页（可跳过）
└── 主框架（底部 Tab ×4）
    ├── Tab1 首页          [信息流列表]
    │   └── 内容详情页      [详情页] → 分享面板 / 举报弹窗（浮层）
    ├── Tab2 发现          [信息流列表]
    ├── Tab3 发布          [发布/表单页]（中间凸起按钮，不是真 Tab）
    └── Tab4 我的          [个人中心]
        └── 设置           [设置页] → 关于 / 账号安全 / 通知设置
```

入口写法：`页面入口：App → 首页Tab → 内容卡片点击 → 内容详情页`

## 形态特有全局章节

- **系统权限申请策略**：`权限 | 申请时机 | 申请前说明文案 | 拒绝后降级路径 | 二次引导方式`
- **推送通知**：`推送类型 | 触发条件 | 文案模板 | 点击落地页 | 用户可否关闭 | 免打扰时段`
- **登录态与游客态**：游客可用范围、触发登录的操作清单、登录后是否回到原操作
- **版本更新**：`更新类型（提示/建议/强制） | 触发条件 | 弹窗文案 | 可否关闭`
- **离线与弱网**：缓存范围、缓存时效、离线可用功能、弱网降级（超时阈值、重试次数、降级画质）
- **安全区与适配**：刘海屏、灵动岛、底部横条、折叠屏、横屏支持、系统字号放大
- **多语言版本**（如有）：语言切换入口位置、跟随系统还是手动选、文案配置形式（建议配置文件/表格，便于后续扩展）、未翻译内容的兜底、切换后是否需重启或重载
- **产品边界**：逐条列出明确排除的功能，每条写明「后续版本迭代」。写法与判据见 `../doc-style.md`「开篇三节」③。
  **这一节放在文档开篇，不是附录**——评审时它是被问得最多的一节。

## UX 检索

规则集读 `$UIUX/references/pro-rules.md`（移动端专用）**加** `quick-reference.md`。设计系统参数：`--variance 5 --motion 6 --density 4`。

| 章节 | 查询 |
| --- | --- |
| 信息流 | `"pull to refresh infinite scroll list" --domain ux` |
| 手势 | `"gesture conflict swipe back" --domain ux` |
| 导航与返回 | `"bottom navigation back button" --domain ux` |
| 状态 | `"empty state loading skeleton feedback" --domain ux` |
| 表单 | `"form labels helper text required" --domain ux` |
| 动效 | `"page transition shared element" --domain gsap` |
| 技术栈 | `--stack swiftui` / `--stack react-native` / `--stack flutter` / `--stack jetpack-compose` |

**必写进文档的移动端硬约束**（来自 `pro-rules.md`）：iOS 触控区 ≥ 44×44pt，Android ≥ 48×48dp；固定栏与 CTA 避开刘海、状态栏、手势区；每个区域只保留一个主要手势，避免与系统返回手势冲突；按压反馈用颜色/透明度/elevation，不改变布局边界；在最大系统字号和 reduced motion 下验证。
