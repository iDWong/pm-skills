# 交付前自查清单

先过「通用 P0」，再过你这个形态的「形态专属 P0」。两段都清了才能交付。

Step 6 逐项过。**P0 必须当场修完再交付**；P1/P2 汇总成清单随文档给用户，问一次是否一并修。

## P0：不修不能交付

### 铁律合规

- [ ] 全文正文表格占比 ≥ 50%，没有用散段落堆砌同类项
- [ ] 每个页面/弹窗都有 `功能入口：管理后台 → … → 【按钮】` 面包屑，箭头用 `→`，按钮用 `【】`
- [ ] 每张列表字段表都有 `字段名称 | 字段说明 | 示例值` 三列
- [ ] 所有示例值是具体假数据，全文搜不到 `xxx`、`字符串`、`某某`、`待补充`、`TBD`
- [ ] 所有用户可见文案都写了原文并加引号，全文搜不到"提示错误信息"、"给出相应提示"
- [ ] 每个二次确认弹窗都是完整整句：动作 + 【对象】+ 后果 + 反问
- [ ] 每个表单都有 `触发时机 | 校验规则 | 用户提示 | 处理方式` 四列校验表，且 ≥ 3 条
- [ ] 每个指标卡九行齐全（定义/时间口径/计算方式/主数字格式/环比对比/环比计算/环比展示/展示文案/特殊处理）
- [ ] 每个页面都有「界面与交互规范」段
- [ ] 每个页面都有原型图，弹窗单独一张，图号与章节号对齐
- [ ] 原型图 PNG 文件名是**纯 ASCII**（中文只出现在 alt 文本与图注里）
- [ ] 新增原型图 PNG 用 `pt-` 前缀；项目里存量 `wf-` 图**保持原样**，没有为统一而批量改名
- [ ] （仅当用户明确要求导出 Word 时）`unzip -l <docx> | grep -c "word/media/"` 的结果**等于**原型图张数（Word 导出对中文文件名静默丢图）
- [ ] 原型图裁后比例等于 SVG 内容比例（比例不对说明裁边失败，不能将就）
- [ ] 原型图**无文字重叠**：生成脚本每张图都跑过 `assert not g.collisions()`，且肉眼过一遍成品 PNG——按钮文字没溢出边框、筛选值没压住下拉箭头、表格单元格没串到隔壁列、标注块的字没捅出虚线框、指标卡标题没压住右上角标

### 完整性

- [ ] Step 2 页面清单里的每个页面都写了，没有漏
- [ ] 每个列表页都写了分页规则和导出规则（无导出也要明说）
- [ ] 每个写操作都有「数据变化表」
- [ ] 每个调用外部系统的操作（支付、短信、推送、审核）都有「失败处理表」
- [ ] 每个带"其他"选项的枚举，都在表单表里写了"选'其他'时备注强制必填"
- [ ] 每个条件显示的字段都写了显示条件

### 口径正确性（最容易出数据事故）

- [ ] 每个指标写清了**是否受顶部时间筛选器影响**
- [ ] 累计类指标写清了截止时点（"截至昨日"）
- [ ] 去重规则写清了（"同一用户多次付费只计 1 次"）
- [ ] 退款是否扣减写清了（收入、累计消费、已购数量分别怎么算）
- [ ] **百分比类指标的环比写的是"百分点差值"，不是百分比变化率**
- [ ] 分母为 0 / 上期无数据的处理写了（显示 `—`）
- [ ] 数据时效声明写了（实时 vs T+1、跑批时间、今日是否统计、界面是否有说明文案）

### UX 规范可追溯

- [ ] 「界面与交互规范」表每一行的 `依据` 列都有来源（检索类别 / `MASTER.md` / "内置默认规则（检索无匹配）"）
- [ ] 没有把零结果写成检索到的数据
- [ ] 规范是可验收的具体值（有像素、毫秒、字号、文案），不是照抄的通用英文规则
- [ ] 状态表达没有只靠颜色（启停、涨跌都配了文字或箭头）
- [ ] 操作列图标按钮都写了可读名称（aria-label 文案）
- [ ] 弹窗写了焦点收拢、ESC 关闭、Tab 循环
- [ ] 校验错误写了文案 + 位置 + 焦点自动落到首个错误字段
