# 页面模板库：Web 运营管理系统

> 本文件只覆盖 **Web 运营管理系统**形态。其余四种形态（APP / H5 / 小程序 / 官网）的页面类型与小节序列见 `profiles/<形态>.md`。

七种后台页面类型的可复制骨架。Step 4 写每个页面时，按 Step 2 定的页面类型取对应模板，替换尖括号内容，删掉不适用的小节。

表头含义见 `doc-style.md` 的 T1–T16（T14–T16 为开篇六章专用）。

## 模板 2：表单弹窗

```markdown
#### 新建<对象>：

功能入口：管理后台 → <一级菜单> → <页面名> → 新建<对象>。
点击【新建<对象>】后，从屏幕中间弹出表单窗口。

创建<对象>表单字段设计：

| 字段名称 | 控件类型 | 是否必填 | 输入提示文字 | 输入提示/规则 |
| --- | --- | --- | --- | --- |
| <名称> | 单行输入框 | 是 | 请输入<名称> | 限 8–20 个字符；只能是字母或字母+数字，禁止特殊符号 |
| <选择项> | 下拉选择框 | 是 | 请选择<选择项> | 可选择所有已创建的<选择项> |
| <数值> | 数字输入框 | 是 | 请输入<数值> | ≥ 0，保留 2 位小数 |
| <备注> | 多行文本域 | 否 | 请输入备注 | 最多 200 字 |
| 状态 | 单选按钮 | 是 | 无 | 启用 / 停用二选一，默认选中：启用 |

交互与校验：

| 触发时机 | 校验规则 | 用户提示 | 处理方式 |
| --- | --- | --- | --- |
| 输入<名称>时 | 同一平台内名称是否重复 | 名称已存在，请重新输入 | 阻止提交，高亮字段 |
| 输入<名称>时 | 是否包含特殊符号 | 不能包含特殊符号 | 阻止提交，高亮字段 |
| 输入<名称>时 | 字符数是否 ≤ 20 | 超过字符上限 20 | 阻止提交，高亮字段 |

| 点击【确认创建】时 | 所有必填字段是否已填 | 聚焦到第一个未填字段，显示对应提示 | 阻止提交 |
```

## 模板 8：界面与交互规范段（每个页面都要有）

内容必须来自 ui-ux-pro-max 检索，写法与检索契约见 `ux-integration.md`。基础维度清单（按页面类型增删）：

```markdown
#### 界面与交互规范：

| 维度 | 规范 | 依据 |
| --- | --- | --- |
| 布局与密度 | <栅格、内边距、表格行高、一屏可见行数> | MASTER.md / ux |
| 表格响应式 | <横向滚动策略、最小宽度、列固定> | ux/Responsive |
| 空态 | 无数据时展示<插图 + 文案 + 主行动按钮>，文案："<原文>" | ux |
| 加载态 | 首屏骨架屏；查询中表格区域 loading 遮罩，按钮置灰 | ux |
| 错误态 | 接口失败展示<位置 + 文案 + 重试按钮> | ux |
| 反馈 | 保存成功顶部 Toast"<原文>"，3 秒自动消失 | ux |
| 键盘与焦点 | 弹窗打开焦点落在第一个输入框，ESC 关闭，Tab 顺序符合视觉顺序 | ux/Accessibility |

| 点击区域 | 操作列按钮命中区 ≥ 32×32px，相邻按钮间距 ≥ 8px | ux/Touch |
| 图标 | 使用统一 SVG 图标族，禁止 emoji 充当结构图标 | icons |
| 排版 | 表格正文 <字号/行高>，数字列右对齐并使用等宽数字 | typography |
| 动效 | 弹窗淡入 <150–200ms>；尊重 prefers-reduced-motion | ux/Animation |
| 响应式断点 | <断点值与各断点下侧边栏/表格的行为> | ux/Layout |
```
